# Carryover

**EN** · Free desktop app to back up your files and reinstall all your programs after formatting your PC, or when moving between Windows and Linux (Ubuntu, Debian, Fedora, Arch, openSUSE).
**PT-BR** · Aplicativo desktop gratuito para fazer backup dos seus arquivos e reinstalar todos os seus programas depois de formatar o PC, ou ao migrar entre Windows e Linux (Ubuntu, Debian, Fedora, Arch, openSUSE).

[**⬇ Download / Baixar**](../../releases/latest) · Windows (`.exe`, `.msi`) · Linux (`.deb`, `.rpm`, AppImage)

---

## English

Formatting a computer is painful: copying files, then remembering and reinstalling every program. Carryover does the boring part.

1. **Back up** the folders you choose to an external drive, a folder, or the cloud (Google Drive, OneDrive and others through [rclone](https://rclone.org)). One `.zip` file, optionally password-protected (AES-256).
2. **Scan** the programs installed on the current computer.
3. **Pick the new system**: Windows or a Linux distro family.
4. **See on screen** what can be reinstalled, what has a substitute, and what is not possible (for example Power BI Desktop on Linux).
5. **Get a reinstall script**: a PowerShell script using `winget`, or a shell script using `apt`, `dnf`, `pacman`, `zypper`, Flatpak or Snap.

### Install
Download the installer for your system from the [latest release](../../releases/latest) and run it.

### Missing a program or a better substitute?
[Open an issue](../../issues/new) with the program name and where you use it.

## Português

Formatar um computador dá trabalho: copiar os arquivos e depois lembrar e reinstalar cada programa. O Carryover faz a parte chata.

1. **Backup** das pastas que você escolher para um HD externo, uma pasta ou a nuvem (Google Drive, OneDrive e outros via [rclone](https://rclone.org)). Um único `.zip`, com senha opcional (AES-256).
2. **Varredura** dos programas instalados neste computador.
3. **Escolha do novo sistema**: Windows ou uma família de distros Linux.
4. **Veja na tela** o que dá para reinstalar, o que tem substituto e o que não é possível (por exemplo, o Power BI Desktop no Linux).
5. **Receba um script de reinstalação**: PowerShell com `winget`, ou shell script com `apt`, `dnf`, `pacman`, `zypper`, Flatpak ou Snap.

### Instalação
Baixe o instalador do seu sistema na [última versão](../../releases/latest) e execute.

### Faltou um programa ou um substituto melhor?
[Abra uma issue](../../issues/new) com o nome do programa e como você o usa.
